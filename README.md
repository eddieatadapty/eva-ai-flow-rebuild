# EVA AI Growth Audit

**Live → https://eddieatadapty.github.io/eva-ai-flow-rebuild/**

Five ideas to turn more EVA AI users into subscribers, each built into a clickable version of EVA AI's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Open on the ad’s promise, ask for the account last | +5–10% CR to purchase |
| 02 | A first message before the price | +10–20% CR to purchase |
| 03 | Ask one thing, and say it back on the paywall | +10–15% CR to purchase |
| 04 | Show what Premium does, inside a chat | +3–8% CR to purchase |
| 05 | A close offer that fits where they came from | +5–10% ARPU |

Every price, rating and feature comes from EVA AI's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for EVA AI. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
